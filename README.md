ReadWithMe

ReadWithMe is a lightweight Chrome extension built to make reading online more comfortable and accessible for people with dyslexia, Irlen Syndrome, ADHD, or general eye strain. Everything runs locally inside your browser without needing accounts or external servers.

Features

- Adaptive Typography & Color Overlays: Switch to dyslexia-friendly fonts like OpenDyslexic, adjust text size and spacing, or apply soft pastel background tints and dark mode to reduce screen glare.
- Focus Window: A reading band that follows your cursor and dims the rest of the screen to help you stay focused on the current line.
- Calm Mode: Hides ads, pop-ups, and distracting sidebars while keeping the main webpage intact.
- Read-Aloud: Hover over any paragraph to hear it read aloud using the browser's built-in speech engine.
- Syllable Splitter: Highlight any long or unfamiliar word to split it into syllables and see a quick definition.
- Article Summarizer: Creates a short summary of long articles right on the page.

How to Install and Test

1. Click the green Code button at the top of this repository and select Download ZIP.
2. Extract the downloaded ZIP folder on your computer.
3. Open Google Chrome and type chrome://extensions/ in the address bar.
4. Turn on Developer mode using the switch in the top-right corner.
5. Click Load unpacked and select the extracted folder that contains manifest.json.
6. Pin ReadWithMe to your Chrome toolbar and open any article or webpage to try it out.
